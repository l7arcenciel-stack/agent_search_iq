02未解決の問題 — プロジェクト作成の失敗

Microsoft.CognitiveServices/accounts/projects の作成だけが一貫して失敗している。

エラーメッセージ(3回とも同一):
BadRequest: Unsupported configuration. To create projects, you must enable a managed identity on your resource.

アカウント側は identity.type: SystemAssigned が実際に付与され(principalId発行済み)、 allowProjectManagement: true も設定済みで、Microsoft公式のBicepサンプルと同一の構成。 にもかかわらずプロジェクト作成APIだけがこのエラーを返し続けている。

試したこと

1
infra/main.bicep をそのまま再デプロイ
account/deployments成功、project失敗。同一エラー
2
90秒待機してから再デプロイ(ID伝播待ちを想定)
同一エラー
3
az resource create でプロジェクトだけを直接作成(アカウントを再PUTしない)
同一エラー。アカウント再送信によるID再伝播の問題ではないことを確認
4
プレビュー機能 Microsoft.CognitiveServices/AllowAIFoundryUpgrade を登録 → プロバイダー再登録 → 60秒待機 → 再試行
機能フラグ自体は他にも複数NotRegisteredのものが見つかったが(AllowAIFoundryUpgradeForCmk, FoundryComputePreview等)、対象のものを登録済みにしても同一エラー
現時点の推測： テンプレートの書き方の問題ではなく、このサブスクリプション/テナント(個人のMicrosoft Entra ID Free、新規のAzure subscription 1)側でのプレビュー機能の伝播遅延、またはリージョン(japaneast)側のロールアウト状況に起因している可能性が高い。ARMでの直接作成に固執せず、Azure AI Foundryポータル(ai.azure.com)のウィザード経由でのプロジェクト作成を試す価値がある(ポータルは内部で異なる初期化フローを使うため、この制約を回避できることがある)。
