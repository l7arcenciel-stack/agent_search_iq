02解決済み — プロジェクト作成の失敗と根本原因

Microsoft.CognitiveServices/accounts/projects の作成が ARM(Bicep/CLI)経由では一貫して失敗していたが、原因を特定しBicepを修正した。

エラーメッセージ(ARM経由の全試行で同一):
BadRequest: Unsupported configuration. To create projects, you must enable a managed identity on your resource.

試したこと(いずれもARM経由では失敗)

1
infra/main.bicep をそのまま再デプロイ
account/deployments成功、project失敗。同一エラー
2
90秒待機してから再デプロイ(ID伝播待ちを想定)
同一エラー
3
az resource create でプロジェクトだけを直接作成(アカウントを再PUTしない)
同一エラー。アカウント再送信によるID再伝播の問題ではないことを確認
4
プレビュー機能 Microsoft.CognitiveServices/AllowAIFoundryUpgrade を登録 → プロバイダー再登録 → 60秒待機 → 再試行
同一エラー
5
Azure AI Foundryポータル(ai.azure.com)から手動でプロジェクトを作成
成功。aif-agentsearchiq-t6pkj7-project
6
手動作成されたプロジェクトのリソースを確認 → プロジェクト自身にも SystemAssigned identity が付与されていることを発見
principalId発行済み。自分のBicepはアカウント側にしかidentityを設定しておらず、プロジェクト子リソース側のidentityが漏れていた
7
infra/modules/ai-foundry.bicep の project リソースに identity: { type: 'SystemAssigned' } を追加し、az resource create で検証
成功(provisioningState: Succeeded)。修正を確認後、検証用の重複プロジェクトは削除済み
根本原因： エラーメッセージは「アカウントにmanaged identityが必要」と読めるが、実際には プロジェクト(accounts/projects)リソース自身にも identity: SystemAssigned が必要だった。 Microsoft LearnのBicepサンプルはアカウント側のidentityしか示しておらず、プロジェクト側は省略されていたため見落としていた。 infra/modules/ai-foundry.bicep は修正済みで、今後は az deployment group create の1回実行だけでプロジェクトまで作成できる。
2026-09-21 追記：この修正は実デプロイで検証済み。 az deployment group create を実行し、プロジェクト agentsearchiq が provisioningState: Succeeded で作成された。手動作成に頼る必要はなくなった。

ただし1回目の実行は別の理由で失敗したので記録しておく。 RequestConflict: Another operation is being performed on the parent resource — アカウント本体の更新とプロジェクト作成が同時に走ったことによる一時的な競合で、 Bicepの不備ではない。リソース自体は作成されており、同じコマンドをもう一度流すだけで Succeeded になった。既存アカウントに対してプロジェクトを追加する場合に起きうる。

03コストメモ

現時点で作成済みのリソースのうち、固定費が発生するものはない。 ※ 2026-09-21 に Fabric容量 F2 を作成したため、この前提は変わった。

  • AI Search: free tier のため $0
  • AI Foundryアカウント自体: 固定費なし(S0は従量課金の器)
  • プロジェクト: 固定費なし
  • モデルデプロイ2件: 呼び出し量に応じた従量課金のみ、未使用なら課金なし
  • Fabric容量: 未作成のため $0
2026-09-21 以降：Fabric容量 F2 が課金対象になった

F2 は従量課金で、目安として時間あたり $0.3〜0.4。Activeのまま放置すると月 $250 前後になる （正確な単価はリージョンと為替で変わるため、Azureの価格ページで確認すること）。 使わない間は一時停止すればほぼ $0 まで落ちる（OneLakeのストレージ分のみ）。 

az resource invoke-action -g rg-agent-search-iq -n fabagentsearchiqt6pkj77hzmit2 \
  --resource-type Microsoft.Fabric/capacities --action suspend

# 作業再開時
az resource invoke-action -g rg-agent-search-iq -n fabagentsearchiqt6pkj77hzmit2 \
  --resource-type Microsoft.Fabric/capacities --action resume

停止中はワークスペースの中身が見えなくなるため、作業する日は先に resume する。
