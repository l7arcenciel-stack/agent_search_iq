## ⚠ このファイルに書いてはいけないもの

**シークレット・キー・トークンの「値」は絶対に書かない。**
書くのは **「どこに保管したか」** だけ（例: `KeyVault: kv-xxx / secret: obo-client-secret`、
`1Password: <項目名>`）。このファイルは Git の管理下に入るため、値を書くと履歴に残り、
あとから消しても消えない。

対象: クライアントシークレット、AI Search の管理キー、Azure OpenAI の API キー、
アクセストークン、パスワード。

GUID（テナントID・クライアントID・グループID・ワークスペースID など）は秘密情報ではないが、
このリポジトリを外部に出す可能性があるなら、ここも保管場所だけにしておくほうが安全。

## 「同じ/変える」列の使い方

新テナントで決めた値を、元テナントでもそのまま使うかどうか。

| 記号 | 意味 |
|---|---|
| **同じ** | 同じ値・同じ名前にしてよい |
| **変える** | 元テナントでは別の値にする（既存と衝突するため） |
| **必ず変える** | 同じにすると**既存の凍結デモが壊れる** |
| **流用** | 元テナントに既にあるものを使う（新テナント側の値は使わない） |
